About the data

Every well and value comes from the NM Unified Water Data API (OGC API – Features). On first load the explorer downloads the per-well summary collection for each analyte (nm_<analyte>_summary) and keeps a copy in this browser for 24 hours. Opening a well fetches its full sample history from nm_<analyte>_timeseries.

Standards used for coloring and exceedance counts

  • Nitrate is compared on an as-nitrogen basis (10 mg/L). If a source reports nitrate as NO₃, the equivalent limit is about 44 mg/L, so exceedances for that source would be overstated.
  • EPA limits for TDS, sulfate and chloride are secondary (taste, odor, scaling), not health-based. Fluoride uses the 4.0 mg/L primary MCL; the 2.0 mg/L secondary level is not shown.
  • NM groundwater standards come from 20.6.2.3103 NMAC. Check them against the current rule before using results in a regulatory context.

Reading the values

  • Non-detects. Sample histories mark results reported as "< MRL" and plot them as open triangles at the reporting limit. In the summaries, many sources store non-detects as 0; the histogram counts those zeros separately.
  • Latest values do not share a date. A well's latest calcium may be from 1985 and its latest arsenic from 2023. The Piper diagram, water type and charge balance combine those latest values, so treat them as screening results.
  • Water type names the cation and anion that make up more than half of their group in milliequivalents per liter (for example Ca‑HCO₃). "Mixed" means no single ion exceeds 50%.
  • Nested wells. Several sources log piezometer nests at one coordinate. Clicking such a point lists every well there.

Exports

Export CSV and GeoJSON include every well in the current selection and filters, with latest, maximum, mean, sample count and exceedance flag for each analyte. Sample-history CSVs come straight from the time-series collections, including the original reported text for non-detects.
