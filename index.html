About the data

Every well and value comes from the NM Unified Water Data API (OGC API – Features) unless it is tagged wqp. On first load the explorer downloads the per-well summary collection for each analyte (nm_<analyte>_summary) and keeps a copy in this browser for 24 hours. Opening a well fetches its full sample history from nm_<analyte>_timeseries.

Standards used for coloring and exceedance counts

  • Nitrate is compared on an as-nitrogen basis (10 mg/L). If a source reports nitrate as NO₃, the equivalent limit is about 44 mg/L, so exceedances for that source would be overstated.
  • EPA limits for TDS, sulfate and chloride are secondary (taste, odor, scaling), not health-based. Fluoride uses the 4.0 mg/L primary MCL; the 2.0 mg/L secondary level is not shown.
  • NM groundwater standards come from 20.6.2.3103 NMAC. Check them against the current rule before using results in a regulatory context.

Reading the values

  • Non-detects. Sample histories mark results reported as "< MRL" and plot them as open triangles at the reporting limit. In the summaries, many sources store non-detects as 0; the histogram counts those zeros separately.
  • Latest values do not share a date. A well's latest calcium may be from 1985 and its latest arsenic from 2023. The Piper diagram, water type and charge balance combine those latest values, so treat them as screening results.
  • Water type names the cation and anion that make up more than half of their group in milliequivalents per liter (for example Ca‑HCO₃). "Mixed" means no single ion exceeds 50%.
  • Nested wells. Several sources log piezometer nests at one coordinate. Clicking such a point lists every well there.

Water Quality Portal (WQP tab)

  • The site list comes from WQP's summary service: every New Mexico monitoring location with water-sample results (about 16,000 of the 48,000 registered sites; the rest have none), with result counts by parameter group. It is kept in this browser for 24 hours.
  • Downloads follow the same rules as the WQP polygon downloader. Up to 150 sites: one link and WQP builds the file. Up to 1,000: site IDs are sent in batches of 25, and any batch WQP can't finish is split in half and retried. Beyond that: WQP is queried by the area's bounding box, site types and date range in decade pieces, split down to two weeks when slow, and only rows for the selected sites are kept. In Chrome and Edge large downloads are written straight to a file you choose; Stop saves what has arrived.
  • The CSV is WQP's own result table, unchanged. Unticking a parameter group adds a characteristicType filter.
  • Adding chemistry to the explorer pulls only the 13 analytes for groundwater sites. A WQP site joins an API well when the API lists it under source WQP with the same ID, or when the USGS site number matches. API values always win. Other sites become wells under the source WQP (direct). µg/L converts to mg/L, nitrate as NO₃ converts to as-N, results in other units are dropped, and where a site has no bicarbonate, total alkalinity × 1.22 stands in.

Public water systems (Public Water Systems tab)

  • Source locations come from the NMED Drinking Water Bureau service dwb/drinking_water_sources: active groundwater sources, active surface-water sources and inactive sources. They carry system, population served, well depth and static water level, but no chemistry.
  • CCR links go to Drinking Water Watch (dww.water.env.nm.gov), which builds the Consumer Confidence Report PDF on request. The PDF lists the system's detected regulated contaminants for that calendar year.
  • CCR values were read out of those PDFs ahead of time and are built into this page (). Each row is what the report lists: highest level detected, range of levels, units and collection date. For disinfection by-products the highest level is the compliance value (a running average), so the range can be higher.
  • The report has no MCL column, so limits are applied here: federal MCLs, the 4 mg/L MRDL for chlorine and chloramine, and the lead (15 ppb) and copper (1.3 ppm) action levels, which apply to the 90th percentile. Beta/photon emitters get no limit: DWW labels them mrem/yr, but the values look like gross-beta screening results, which are compared to 50 pCi/L, not the 4 mrem/yr MCL. "Above a limit" compares the highest level to that number and is a screening flag, not a compliance finding.
  • A CCR describes water the system delivers, often blended from several sources and treated. When sources are colored by CCR result, every source of a system gets the same color. The source popup sets the system's value beside the latest values at chemistry wells within a mile.

Exports

Export CSV and GeoJSON include every well in the current selection and filters, with latest, maximum, mean, sample count and exceedance flag for each analyte, plus which analytes came from WQP. Sample-history CSVs come straight from the time-series collections, including the original reported text for non-detects.
